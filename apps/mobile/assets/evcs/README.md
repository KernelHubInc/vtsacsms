# EVCS launch assets

Content and icons exported from the approved [EVCS design](https://www.figma.com/design/wmrJ4VV3zw6uZC4tHdD9Qv/EVCS?node-id=57-1621).

- access-access-ev-charging-scene.png: original realistic EV drawing, Figma component 67:248.
- access-rectangle.png: approved EVCS logo, component 3:142.
- access, pin, auth and map SVG files: exact Figma exports used by the corresponding controls. Source SVG geometry is retained.
- Map tiles and station locations come from the configured runtime provider and API. The Figma schematic map is an illustration, not a runtime data source. Existing assets/interface/pin-*.png remain the original EVCS map-marker assets.
- assets/fonts/Inter.ttf and OFL.txt: Inter variable font and SIL Open Font License from the official Google Fonts ofl/inter distribution. Bundled locally for native and browser use.

No full-screen UI screenshot is used as an implementation asset. No temporary Figma URL is used at runtime.
