# Milestone 1 limitations

Milestone 1 is a local demonstration with fictional test data. It proves public discovery, tenant/role boundaries, administrative workflows, procurement, inventory, maintenance, reporting foundations, CMS, local email and the Flutter consumer shell.

The following are deliberately unavailable and return a clear Milestone 2 experience without an external request:

- OCPP and physical charger connectivity
- remote start/stop and live charger telemetry
- real payment instruments, authorizations, captures, refunds or disputes
- real operator/site-host settlement
- production electronic invoicing and tax rules
- OCPI roaming
- production push delivery and production infrastructure

OpenStreetMap tiles require browser internet access; the station list and server API do not. The public web favorite remains a Flutter/local consumer feature rather than a browser account feature. The local support queue supports viewing, responses, internal notes, and escalation, but does not contact an external help-desk provider. Seeded finance screens are labelled demonstrations and must not be interpreted as transactions. Local performance findings are not production capacity claims.
